What this page resolves

Each lookup joins the Hebrew corpus, a verse occurrence, and a target language. An exact stored relation returns its rendering. An absent relation stays unknown. This is an executing lookup, not a claim that binary encoding alone solves translation.

The English comparison is the existing World English Bible, not a new translation produced here. This retained alignment has 202 verse entries without an English match; chapter and verse numbering may differ between witnesses.

Hebrew source: Westminster Leningrad Codex · OSHB v2.2 · English reference: WEB. Hebrew transcription and WEB text: public domain. OSHB morphology: CC BY 4.0; no morphology is newly asserted by this page.

Source identity and method

Local renderings are labelled user-provided. Importing or storing a relation does not verify linguistic accuracy or causal equivalence. No AI service, paid API or automatic external translation runs in this page. The downloadable script reuses WHY Translate: exact ledger lookup first, optional generation only with its explicit --ai flag. Select a template, export a chapter request, run the script and import its returned rendering ledger. Generated text remains a candidate.
