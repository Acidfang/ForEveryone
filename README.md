# For Everyone

A shareable chronology of Acidfang's endeavours and the recurring methodology
behind them: map, model, build, test, and publish.

The site is deliberately dependency-free and deploys directly to GitHub Pages.

## Investigations

- [Epstein records: chronology, payments and open questions](https://acidfang.github.io/ForEveryone/work/epstein-public-records/) — source-linked findings, corrections and unresolved evidence boundaries. [Page source](work/epstein-public-records/index.html).

## Local preview

Open `index.html`, or serve the directory with any static file server.

## Publishing

Push the repository to GitHub. The included Pages workflow publishes the site
from the default branch.
